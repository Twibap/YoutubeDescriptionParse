# 네이버 지도에서 가게 위치 공유하기

친구가 링크를 눌렀을 때 네이버 지도 앱이나 웹 자체에서 가게를 확인하려면, 기존 지도 링크 또는 네이버 지도의 저장 목록 공유 기능을 사용합니다. 별도 웹사이트나 Maps API 키는 필요하지 않습니다.

## 가게 하나 공유하기

`restaurants.csv`의 `map_url`에 있는 네이버 지도 링크를 공유합니다. `naver.me` 같은 단축 링크도 원래 값을 사용합니다. 받은 사람이 링크를 열면 네이버 지도에서 해당 위치를 확인할 수 있습니다. 앱으로 열리는지는 설치 여부와 기기 설정에 따라 달라집니다.

Google 스프레드시트에서 가게 이름을 클릭 가능한 링크로 만들 수도 있습니다. 원래 CSV 순서에서 이름은 B열, 주소는 C열, 지도 URL은 D열입니다. 빈 열의 2행에 입력하고 아래로 채웁니다.

```text
=HYPERLINK(D2,B2&" 지도 보기")
```

이 수식은 D열의 원래 지도 서비스로 연결합니다. 네이버 지도 링크가 아닌 행은 네이버 지도에서 이름과 주소로 검색한 뒤 장소 링크를 별도로 준비합니다. 원문 CSV를 자동으로 변경하지 않습니다.

## 여러 가게를 링크 하나로 공유하기

네이버 지도에 저장 목록을 만든 뒤 목록의 공유 링크를 보냅니다. 대표적인 순서는 다음과 같습니다. 메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다.

1. 네이버 지도에서 새 저장 목록을 만듭니다. 예: `중랑구·광진구 맛집`.
2. CSV의 가게별 네이버 지도 링크를 열고, 장소 화면의 저장 기능으로 해당 목록에 추가합니다.
3. 목록의 공개·공유 설정을 확인하고 공유 기능에서 링크를 복사합니다.
4. 복사한 링크를 열어 저장한 장소와 가게 상세 정보가 보이는지 확인한 뒤 친구에게 보냅니다.

네이버 지도는 CSV 일괄 가져오기를 지원하지 않는 것으로 알려져 있어, 이 방식은 네이버 지도 화면에서 가게를 저장하는 과정이 필요합니다. Maps API 키는 별도 웹페이지의 지도 표시와 주소 조회에 사용되며, 개인 저장 목록을 CSV로 생성하는 기능을 제공하지 않습니다. 최신 메뉴나 지원 범위는 네이버 지도 도움말에서 확인하세요.

핀을 선택하면 네이버 지도가 제공하는 장소 정보를 볼 수 있습니다. CSV의 영상 제목·영상 URL 같은 추가 필드는 저장 목록에 자동으로 옮겨지지 않습니다. 원래 수집 데이터는 스프레드시트에 보관하고, 필요한 소개 영상 링크는 가게의 메모 기능을 사용할 수 있는 경우 별도로 적습니다. 메모도 공유되는지는 목록 링크를 열어 확인합니다.
